# Teklozy Intro Animation Update

The preloader has been refined into a smoother, more cinematic brand reveal using the existing Teklozy emblem and wordmark.

- Deep navy background with restrained cyan ambient lighting
- Soft portal reveal and thin elliptical orbit rings
- Smooth emblem entrance (no elastic/bouncy overshoot)
- Subtle floating dust particles and a single light sweep
- Clean wordmark, divider and tagline reveal
- Gentle upward curtain transition into the site
- Respects `prefers-reduced-motion`

No authentication, Supabase, page navigation, database, header, team-page or footer code was changed for this animation refinement.

Run locally with `npm install` followed by `npm run dev`.
